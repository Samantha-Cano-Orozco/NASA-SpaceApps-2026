# Soil Analog Comparison · Mars and Earth

Prototype for comparing the mineral signature of Meridiani Planum (Mars, rover Opportunity)
with three terrestrial sites, using processed EMIT, ASTER, CRISM and TES results.

## Run

Open `index.html` with a double click. No server, internet connection or libraries are needed.

1. Select the Mars zone (Opportunity traverse area around Victoria crater).
2. Select an Earth site. Hovering a target shows its state and country.
3. Click "Run comparison" to open `compare.html`.

## Files

- `index.html`, `index.js`: selection screen. Mars and Earth each fill one screen; scroll between them.
- `compare.html`, `compare.js`: head-to-head comparison. Earth on the left, Mars on the right, main statistics between them; other statistics below.
- `globe.js`: dependency-free canvas globe (rotation, zoom, zones, points, hover).
- `styles.css`: shared stylesheet.
- `data.js`: processed data. Generated by `tools/build_data.py`; do not edit by hand.
- `imagenes/`: hover photo for each Earth site (see below).
- `assets/textures.js`, `assets/*.jpg`: globe textures.
- `tools/fetch_places.py`: downloads the hover photos.
- `tools/build_data.py`: builds `data.js` and `assets/textures.js` from the results folders.

## Update the data

    python3 tools/build_data.py <mineral_repo_dir> . <terrain_repo_dir>

`<mineral_repo_dir>` must contain `resultados_comparacion/` and `resultados_tierra/`.
`<terrain_repo_dir>` must contain `resultados_comparacion/` and `resultados_terreno/` from the terrain pipeline.
The script checks that similarity equals the weighted mean of criterion matches and that
points lost add up to 100 minus similarity. It stops if either check fails.

Only sites with a folder in `resultados_comparacion/` appear in the selection. To add a site,
add it to `SITES` in the script (name, state, country, center coordinates) and rerun.

## Mars zone

`DATA.mars.zone` in `data.js` (set in `tools/build_data.py`): center -2.0°, -5.5° (Victoria crater),
radius 0.6°. This is an approximation of the traverse area and must be checked against the
mission traverse map.

## Notes

- Zoom with the mouse wheel needs Ctrl held, so plain scrolling moves between the planets.
- Coordinates are used only to place markers on the globes; they are not displayed.
- Mineral groups are assigned automatically. Entries flagged for review have not been checked by hand.
- Mars textures come from an earlier version. Check their source and license before publishing.

## Hover photos

Each Earth site shows a photo from the `imagenes/` folder when hovered. Names must match:

    imagenes/el_pinacate.jpg
    imagenes/black_point.jpg
    imagenes/desierto_del_diablo.jpg
    imagenes/amazonas.jpg
    imagenes/salar_de_uyuni.jpg

Mars shows no image. If a file is missing, its box is hidden. To download free-licence photos from
Wikimedia Commons instead, run this on your own computer (needs internet):

    python3 tools/fetch_places.py .

The script writes `imagenes/creditos.txt` with author and licence for each photo.

## Overall similarity bar

The full-width bar on the comparison page is filled to the overall similarity:

    overall = (mineral similarity + terrain similarity × 100) ÷ 2

It is computed in `compare.js`. To weight the two comparisons differently, change that line.

## Sites in the selection

A site appears only if `resultados_comparacion/<site>/` exists in the mineral dataset. Amazonas has
data in `resultados_tierra/` but no comparison in the current dataset, so it is skipped until one is added.
